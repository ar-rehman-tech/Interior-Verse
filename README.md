# 🏠 Interior Verse

Interior Verse is a modern interior design web application designed to provide users with an engaging and visually appealing platform for exploring interior design concepts and experiences.

The project is built using modern front-end technologies including React, TypeScript, Vite, and Tailwind CSS.

---

## 📌 Project Overview

Interior Verse is a front-end web project focused on modern interior design and user experience.

The application provides a clean and responsive interface that can be used to showcase interior spaces, design ideas, and related content.

The project follows a modern component-based architecture using React and TypeScript.

## 🚀 Getting Started

### Prerequisites

Make sure the following are installed:

* Node.js
* npm
* Visual Studio Code (recommended)

---

### 1. Clone the Repository

```bash
git clone https://github.com/ar-rehman-tech/Interior-Verse.git
```

---

### 2. Navigate to the Project

```bash
cd Interior-Verse
```

---

### 3. Install Dependencies

```bash
npm install
```

---

### 4. Start the Development Server

```bash
npm run dev
```

Vite will start the development server and provide a local URL in the terminal.

Open that URL in your browser to view the application.

---

## 🏗️ Production Build

To create an optimized production build:

```bash
npm run build
```

The generated production files can then be deployed to a hosting platform such as Vercel or Netlify.

---

## 🔍 Preview Production Build

After creating the production build, you can preview it locally using:

```bash
npm run preview
```
